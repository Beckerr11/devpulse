# DevPulse

Painel operacional de performance para desenvolvedores e squads.

## Problema
Times de engenharia trabalham com sinais dispersos sem um cockpit unico para priorizar melhoria continua.

## Publico
Devs solo, tech leads e squads de produto.

## MVP
- Dashboard semanal de atividade tecnica com foco em fluxo.
- Alertas de gargalo em PR, issue e deploy.
- Objetivos de produtividade com historico de evolucao.
- Resumo semanal para acompanhamento de time.

## Stack
- React + TypeScript + Vite
- Node + Express + TypeScript
- CI com lint/test/build/audit

## Setup
1. npm install --include=dev
2. npm run bootstrap
3. npm run dev

## Monetizacao
Assinatura mensal por usuario com plano free para dev individual.
